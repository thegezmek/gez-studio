# GEZ.STUDIO

Film production site for [gez.studio](https://gez.studio).

## Concept

The homepage opens with a full-frame film, then a film list, stills, and a studio note. Studio and contact are their own pages.

## Stack

Next.js · Tailwind v4 · Framer Motion · Space Grotesk

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project media

Edit `src/data/projects.ts` — swap `media.src` / `poster` for local files in `public/projects/`.

## Deploy

```bash
npm run build
```

Deploy to Vercel.
